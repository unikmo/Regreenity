Why this matters

FAQ

Common questions

Commercial pilots should be explicit about scope, integration and the outcome being measured.

Does Regreenity require a new passenger app?

No. The target architecture is a white-label add-to-app module or embedded web experience inside the cruise line’s digital environment.

Can it work with poor public internet?

The platform is designed around ship-local and offline-tolerant operation. The current pilot uses cloud shared state; ship-local synchronization is part of production integration.

Who controls pricing and payments?

The cruise line does. Regreenity can create a relevant handoff and attribution signal without becoming the merchant.
