# Accessibility readiness

The automated matrix covers desktop Chrome, Pixel 7 and iPad-sized Chromium viewports across the public product pages, the twelve-step executive carousel, the pilot form and offline reload. Axe checks WCAG 2.0/2.1 A and AA and blocks serious or critical violations; the suite also checks labels, keyboard reachability and horizontal overflow.

The first full run identified insufficient bronze-on-paper contrast. The production palette was darkened and all automated routes now pass. Customer deployments still require assistive-technology acceptance in the complete host app because host navigation, dynamic type, screen-reader order and camera permission UX are controlled partly by the cruise line.
